# Ролик о телевизоре по шаблону

Шаблон готов: 11 сцен, анимация, палитры брендов, музыка, рендер. **Новый ролик = новый файл данных
`products/<id>.js`.** Код в `src/` и `scripts/` для этого менять не нужно — не читайте его без
необходимости, так экономятся токены. Читайте только образец данных и этот файл.

## Порядок работы

1. **Характеристики.**
   - Если пользователь прислал список, таблицу или ссылку — берите оттуда.
   - Иначе ищите сами (WebSearch): сайт производителя и 2–3 магазина или обзора. Каждую цифру
     сверяйте минимум по двум источникам. Сомнительное — не включайте или спросите пользователя.
   - Нужны: диагональ (дюймы и см), тип подсветки/панели, процессор, частота (Гц), HDR-форматы,
     игровые функции, число и версии HDMI, звук (Вт, каналы, технологии), ОС, Wi-Fi, Bluetooth,
     размеры без подставки (Ш×В×Г, мм), высота с подставкой, ширина и глубина подставки или
     расстояние между ножками, вес с подставкой и без, VESA, разъёмы, тюнеры.
2. **Файл модели.** Скопируйте ближайший образец:
   - Samsung → `products/_template-samsung.js`, Sony → `products/_template-sony.js`,
     LG и прочие → `products/lg-oled55c6rla.js` (готовый заполненный пример).
   - Имя файла: бренд и модель строчными, например `samsung-qe65qn90f.js`, `sony-k-65xr70.js`.
   - Замените всё в `[квадратных скобках]` (и тексты, и числа — скобки убрать). Незаполненное
     проверка не пропустит.
   - В начале файла — комментарий со ссылками на источники характеристик.
   - Поля `panel`, `stand`, `contrast.*.mode`, `theme` — по подсказкам в шапке шаблона.
3. **Проверка:** `npm run check -- --product <id>`. Она проверяет данные и вёрстку каждой сцены
   текстом: наложения надписей, выход за края карточек и кадра, наезд текста на картинки.
   Исправляйте тексты (короче формулировка), пока не будет «Проблем с вёрсткой не найдено».
   Длинные названия шаблон сам уменьшает, но у шрифта есть минимум.
4. **Просмотр — один раз, в конце:** листы `build/<id>/sheet_1.png`, `sheet_2.png`,
   `sheet_3.png` (по 4 сцены на листе). Больше картинок не открывайте без причины.
5. **Рендер:** `npm run render -- --product <id>` запускайте в фоне, около 5 минут на 4 ядрах.
   Результат — `output/<id>/<file>.mp4` и обложка `output/<id>/<file>_cover.png`.
6. **Коммит:** `products/<id>.js` и папка `output/<id>/`. Готовый MP4 отправьте пользователю.

## Правила для текстов

- Русский язык; единицы через пробел: «40 Вт», «0,1 мс», «1443 мм»; дробные через запятую.
- Знак дюйма — прямая кавычка: `55"`. Шрифт не содержит ″, ∞, →, ≈, ✓ — не используйте их.
- Только подтверждённые факты. Никаких «самый», «лучший» без источника. Не упоминайте сервисы,
  которые не работают в России.
- Коротко: заголовок сцены — до ~35 знаков, подпись в карточке — до ~45.
- Названия технологий — как у производителя (латиницей), пояснение — по-русски.

## Особенности брендов

- **Samsung:** Tizen OS; HDR10+ (Dolby Vision нет); звук OTS / OTS+, Q-Symphony; пульт SolarCell;
  Neo QLED — Mini LED (`panel: 'miniled'`), S90/S95 — QD-OLED (часть размеров — WOLED).
- **Sony:** Google TV; Dolby Vision; обычно 120 Гц и 2 порта HDMI 2.1 из 4; «Perfect for
  PlayStation 5»; BRAVIA 7/9 — Mini LED, BRAVIA 8 — OLED (звук Acoustic Surface Audio+); ножки.
- **LG:** webOS; Dolby Vision; OLED evo; α-процессоры; Magic Remote (`remote: 'pointer'`).

## Частые настройки

- Убрать сцену — удалить её из `scenes` (intro первой и outro последней оставить).
- Длительность сцены — `durations: { gaming: 8 }`.
- Обычная LED-подсветка без локального затемнения — убрать сцену `contrast`.
- Иконки — любые из Lucide по имени файла (`node_modules/lucide-static/icons/<имя>.svg`).
- Стоп-кадр для проверки: `npm run still -- --product <id> 40.5` → `build/<id>/stills/`.
