## Характеристики и источники

Сайты LG из среды сборки были недоступны, поэтому данные собраны из поисковой выдачи и сверены между несколькими источниками: страницы LG OLED55C6RLA (Россия, Казахстан) и OLED55C6PLA (Индия) в выдаче, обзоры RTINGS, TechRadar, Trusted Reviews и TFTCentral, пресс-релизы LG о линейке 2026 года, карточки товара у российских продавцов (nix.ru, tv-01.ru, ru-electronics.ru, good-gamers.ru).

Подтверждены несколькими источниками:

- процессор α11 AI Processor Gen3, webOS 26;
- 4K 3840 × 2160, до 165 Гц (VRR), отклик 0,1 мс, NVIDIA G-SYNC Compatible, AMD FreeSync Premium, VRR, ALLM;
- 4 × HDMI 2.1 с полной пропускной способностью 48 Гбит/с на всех портах, eARC;
- Dolby Vision, HDR10, HLG, Filmmaker Mode, Brightness Booster (для 48/55/65");
- звук 40 Вт, 2.2 канала, Dolby Atmos, виртуальный 11.1.2 (AI Sound Pro), WOW Orchestra;
- Wi-Fi 6, Bluetooth 5.3, LAN, оптический аудиовыход, тюнеры DVB-T2/C/S2;
- без подставки 1222 × 703 × 45,1 мм и 14,1 кг; с подставкой высота 757 мм и 15,9 кг; подставка 470 × 230 мм; VESA 300 × 200.

**Перед публикацией стоит сверить с официальной карточкой на lg.com/ru:**

- число USB: два порта USB 2.0 указывают две карточки, но один обзор упоминает три (у прошлогодней C5 их было три);
- отдельный спутниковый вход: следует из тюнера DVB-S2, но на схеме разъёмов не подтверждён;
- комплектный пульт Magic Remote для российской поставки.

В финальном кадре есть оговорка: «Характеристики приведены по открытым источникам и могут быть изменены производителем».

## Как пересобрать ролик

Нужны Node.js 18+ и Chromium для Playwright (в облачной среде Claude Code он уже установлен).

```bash
npm install
npm run render                               # полный рендер в output/ (~6 минут на 4 ядрах)
node scripts/render.mjs --from 20 --to 30    # пробный отрезок, кладётся в build/
node scripts/still.mjs 5.8 40.5              # отдельные кадры в PNG (build/stills/)
node scripts/music.mjs build/music.wav       # только музыка
npm run preview                              # предпросмотр в браузере: http://localhost:8080
```

В предпросмотре пробел ставит паузу, стрелки ← / → перематывают на 5 секунд, а адрес `?t=40.5` открывает стоп-кадр на нужной секунде.

## Как всё устроено

- `src/index.html` — разметка и **все тексты** ролика: цифры и подписи правятся здесь.
- `src/styles.css` — оформление: палитра, шрифт Manrope, позиции блоков.
- `src/timeline.js` — длительность сцен (общая для видео и музыки).
- `src/js/scenes.js` — анимация каждой сцены как функция времени `render(t)`.
- `src/js/draw.js` — рисунки на canvas: цветные ленты на экране, пиксели, ночной город, закат.
- `src/js/main.js` — загрузка шрифтов и иконок, `seek(t)` для рендера, предпросмотр.
- `scripts/render.mjs` — покадровый захват страницы в Chromium, кодирование в H.264 в 4 потока, склейка и сведение со звуком.
- `scripts/music.mjs` — синтез музыки: пэд, бас, арпеджио, ударные, «вжухи» на сменах сцен; громкость около −16 LUFS.

Каждый кадр вычисляется только из времени `t`, поэтому рендер детерминирован: одинаковый код даёт одинаковое видео.

Чтобы сделать ролик для другой диагонали (например, OLED65C6RLA), поменяйте цифры в `src/index.html` и масштаб чертежа в сцене «Габариты» (`size` в `src/js/scenes.js`).
