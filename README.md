# Инфографические ролики о телевизорах

Шаблон анимированных роликов с инфографикой о телевизорах LG, Samsung, Sony и других брендов. Одна модель — один файл с данными `products/<id>.js`. Из него получается ролик 1920 × 1080, 30 к/с, около 80 секунд, H.264 + AAC, и обложка к нему.

Весь текст в роликах на русском. Музыка синтезируется скриптом с нуля, без сэмплов и чужих треков, поэтому проблем с авторскими правами на площадках не будет.

## Как сделать ролик о новой модели

Проще всего попросить Claude в сессии с этим репозиторием: «сделай ролик для Samsung QE65QN90F». Порядок работы для Claude описан в навыке `.claude/skills/tv-video/SKILL.md`: найти характеристики, заполнить файл модели, проверить вёрстку, отрендерить. Если сразу прислать характеристики списком или ссылкой на карточку, выйдет быстрее и дешевле.

Вручную:

1. Скопируйте образец в `products/<id>.js`:
   - Samsung — `products/_template-samsung.js`;
   - Sony — `products/_template-sony.js`;
   - LG — `products/lg-oled55c6rla.js`.
2. Замените всё, что в `[квадратных скобках]`, и тексты, и числа, на данные модели. Подсказки по линейкам брендов — в шапке каждого шаблона.
3. `npm run check -- --product <id>` проверит данные и вёрстку:
   - нет ли незаполненных мест;
   - не накладываются ли надписи и не вылезают ли за карточки и края кадра.

   Заодно она соберёт листы превью `build/<id>/sheet_*.png`.
4. `npm run render -- --product <id>` — готовый ролик и обложка появятся в `output/<id>/`, это около 5 минут на 4 ядрах.

Что настраивается в файле модели:

| Поле | Что меняет |
| --- | --- |
| `theme` | палитра: `lg`, `samsung`, `sony`, `neutral` |
| `panel` | `oled`, `qd-oled`, `miniled`, `led`: рисунок пикселей и профиль корпуса на чертеже |
| `stand` | `center` — подставка по центру, `feet` — ножки по краям |
| `scenes` | состав и порядок сцен; ненужные можно убрать |
| `durations` | длительность отдельных сцен, секунды |
| `contrast.left/right.mode` | `led`, `miniled`, `oled`: как нарисовать сравнение подсветки |
| `gaming.hz` | максимум шкалы: 120, 144, 165… |
| `smart.remote` | `pointer` — пульт-указка с курсором, `buttons` — обычный пульт |
| `ports.groups` | разъёмы: `hdmi`, `usb`, `lan`, `optical`, `coax`, `jack` с количеством; раскладываются автоматически |

Длинные названия шаблон сам уменьшает, чтобы они влезли. Если текст всё равно не помещается, об этом скажет `npm run check`.

## LG OLED55C6RLA: характеристики и источники

Сайты LG из среды сборки были недоступны, поэтому данные собраны из поисковой выдачи и сверены между несколькими источниками:
- страницы LG OLED55C6RLA (Россия, Казахстан) и OLED55C6PLA (Индия);
- обзоры RTINGS, TechRadar, Trusted Reviews и TFTCentral;
- пресс-релизы LG о линейке 2026 года;
- карточки товара у российских продавцов: nix.ru, tv-01.ru, ru-electronics.ru, good-gamers.ru.

Подтверждены несколькими источниками:

- процессор α11 AI Processor Gen3, webOS 26;
- 4K 3840 × 2160, до 165 Гц (VRR), отклик 0,1 мс, NVIDIA G-SYNC Compatible, AMD FreeSync Premium, VRR, ALLM;
- 4 × HDMI 2.1 с полной пропускной способностью 48 Гбит/с на всех портах, eARC;
- Dolby Vision, HDR10, HLG, Filmmaker Mode, Brightness Booster (для 48/55/65");
- звук 40 Вт, 2.2 канала, Dolby Atmos, виртуальный 11.1.2 (AI Sound Pro), WOW Orchestra;
- Wi-Fi 6, Bluetooth 5.3, LAN, оптический аудиовыход, тюнеры DVB-T2/C/S2;
- без подставки 1222 × 703 × 45,1 мм и 14,1 кг; с подставкой высота 757 мм и 15,9 кг; подставка 470 × 230 мм; VESA 300 × 200.

**Перед публикацией стоит сверить с официальной карточкой на lg.com/ru:**

- число USB: два порта USB 2.0 указывают две карточки, но один обзор упоминает три (у прошлогодней C5 их было три);
- отдельный спутниковый вход: следует из тюнера DVB-S2, но на схеме разъёмов не подтверждён;
- комплектный пульт Magic Remote для российской поставки.

## Команды

Нужны Node.js 18+ и Chromium для Playwright (в облачной среде Claude Code он уже установлен).

```bash
npm install
npm run check -- --product <id>                        # проверка данных и вёрстки + листы превью
npm run render -- --product <id>                       # полный рендер в output/<id>/
npm run render -- --product <id> --from 20 --to 30     # пробный отрезок, кладётся в build/<id>/
npm run still -- --product <id> 5.8 40.5               # отдельные кадры в PNG (build/<id>/stills/)
npm run music -- --product <id>                        # только музыка (build/<id>/music.wav)
npm run preview                                        # предпросмотр в браузере, ссылки на все модели
```

В предпросмотре пробел ставит паузу, стрелки ← / → перематывают на 5 секунд, а `&t=40.5` в адресе открывает стоп-кадр на нужной секунде.

## Как всё устроено

- `products/<id>.js` — данные модели: все тексты, цифры, палитра, тип панели и подставки, список сцен.
- `products/_template-*.js` — заготовки для Samsung и Sony.
- `src/timeline.js` — хронометраж сцен, общий для видео и музыки.
- `src/js/scenes.js` — разметка и анимация каждой сцены из данных модели.
- `src/js/draw.js` — рисунки на canvas: цветные ленты на экране, пиксели, ночной город для сравнения подсветок, закат.
- `src/js/themes.js` — палитры брендов.
- `src/js/layout.js` — автоподгонка длинных надписей и проверка вёрстки.
- `src/validate.js` — проверка файла модели.
- `src/js/main.js` — сборка страницы, `seek(t)` для рендера, предпросмотр.
- `scripts/render.mjs` — покадровый захват страницы в Chromium, кодирование в H.264 в 4 потока, склейка и сведение со звуком.
- `scripts/check.mjs` — проверка данных и вёрстки, листы превью.
- `scripts/music.mjs` — синтез музыки: пэд, бас, арпеджио, ударные, «вжухи» на сменах сцен; громкость около −16 LUFS.

Каждый кадр вычисляется только из времени `t`, поэтому рендер детерминирован: одинаковые данные дают одинаковое видео.
